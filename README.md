# ✨ About

Typing Speed Test is a modern web application designed to help users improve their typing skills by measuring speed and accuracy in real time.

The application provides instant visual feedback, a countdown timer and a responsive interface for desktop, tablet and mobile devices.

---

# 🚀 Features

- ⌨️ Real-Time Typing Test
- ⚡ Live Character Highlighting
- 📊 Accuracy Calculation
- 🚀 WPM Counter
- ⏱ Countdown Timer
- 📈 Progress Indicator
- 🎯 Instant Result Modal
- 🔄 Restart Test
- 📱 Fully Responsive
- 🌙 Modern UI
- 🎨 Built with Tailwind CSS
